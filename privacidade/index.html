stumix

Política de privacidade

Vale para o Stumix no navegador, no celular e no Windows (incluindo a versão da Microsoft Store). Atualizada em 27 de novembro de 2026.

Resumo

O Stumix não tem contas, não coleta dados pessoais e não envia suas gravações para nenhum servidor. Tudo o que você grava e edita fica no seu aparelho.

Microfone e placa de áudio

O app pede acesso ao microfone ou à placa de áudio só para gravar quando você toca em gravar ou testa o microfone. O som é processado no próprio aparelho e não é transmitido.

O que fica guardado no aparelho

  • Projetos, gravações e sessões de várias faixas.
  • Preferências, como a placa de áudio escolhida, o atraso medido e o tamanho da janela.
  • No Windows, um registro técnico das conexões da placa de áudio (placa.log), usado só para diagnóstico e que não sai do computador.

Você pode apagar esses dados apagando os projetos no app, limpando os dados do site no navegador ou desinstalando o app.

Conexões com a internet

  • O app no navegador é baixado do GitHub Pages, que pode registrar dados técnicos de acesso (como endereço IP), conforme a política do GitHub.
  • O Stumix para Windows baixado do site consulta o GitHub para saber se há versão nova. A versão da Microsoft Store é atualizada pela própria Store.
  • Não há anúncios, rastreadores, cookies de terceiros nem ferramentas de análise de uso.

Crianças

O Stumix não coleta dados de ninguém, inclusive de crianças.

Lei Geral de Proteção de Dados (LGPD)

Como o Stumix não coleta nem trata dados pessoais em servidores, não há dados seus em poder do desenvolvedor. Dúvidas sobre privacidade podem ser enviadas pela página do projeto: github.com/Fbi0l/estudio/issues.

Mudanças

Se esta política mudar, a nova versão será publicada nesta página com a data atualizada.
